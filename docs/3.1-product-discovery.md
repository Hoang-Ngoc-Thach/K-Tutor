# 3.1 — Product Discovery

## The real problem

Korean learners in Vietnam typically fall into one of two groups with clearly different needs:
- Learners studying for **everyday conversational Korean**.
- Learners preparing for the **TOPIK exam** (level not yet differentiated in v1 — see Open Assumptions).

Both groups share the same friction: existing learning material (textbooks, generic language-learning apps) doesn't let them practice reading with material they already have in hand — a textbook page from class, a handwritten note, a line of dialogue captured from a show. They have to manually retype Korean text if they want to look it up or hear it pronounced, which is slow and discouraging. They also lack a quick way to check whether a sentence they wrote themselves is actually correct.

## Value proposition

**K-Tutor** helps Korean learners:
1. Follow a vocabulary/grammar path, organized by **topic** (for conversation learners) or exam-relevant category (for TOPIK learners).
2. Practice reading directly from material they already own, by scanning handwriting or images into text and having AI read it back.
3. Check their own sentence-writing against AI feedback, without needing a live tutor.
4. Review vocabulary they've already learned, per topic, using multiple quiz formats.

## User personas

| Persona | Goal | Pain point |
|---|---|---|
| Conversation learner | Speak and understand everyday Korean | Off-the-shelf content is generic and disconnected from the material they actually encounter |
| TOPIK learner | Pass the TOPIK exam | Needs an exam-aligned path but has no time to build their own reading practice material |
| Website administrator | Keep learning content accurate and up to date, and understand how the site is actually used | No way to add/edit vocabulary and topics, manage user accounts, or see usage patterns without direct database access |

## Discovery scope (v1)

**In scope:**
- Vocabulary/grammar path for both personas, organized by topic (e.g. "Chào hỏi & Giới thiệu", "Gọi món tại nhà hàng") for conversation learners.
- Scanning a handwritten note or image into text (OCR).
- Reading that text aloud via AI (TTS).
- **AI-assisted sentence practice:** the learner writes a single Korean sentence, and AI checks it and explains any mistake — a bounded, single-turn exercise, not an open conversation.
- **Vocabulary review per topic**, Quizlet-style: typing the Vietnamese meaning, typing the Korean word, or matching pairs.
- Progress tracking.
- **Admin capabilities:** managing learning content (vocabulary, grammar, topics), managing user accounts, and viewing usage statistics — all via the same login screen as regular users, distinguished by role after login.

**Out of scope (v1), moved to future direction:**
- Reading text back in the user's own voice (voice cloning).
- Automatic pronunciation scoring.
- A free-form, open-ended, multi-turn conversational chatbot (distinct from the bounded, single-sentence AI grammar practice above — see `3.2-prd.md` for exactly where this line is drawn).
- A Hangeul letter-matching mini-game as a functional feature (may remain as static homepage decoration only, not a real learning mode).
- Advanced TOPIK content (levels 5–6).

## Success signal

A learner selects a goal (conversation / TOPIK) → receives a topic-organized vocabulary/grammar path → scans a piece of text → hears it read back by AI → writes a sentence and gets AI feedback → reviews a topic's vocabulary via a quiz → can see their own learning progress.

## Open assumptions

- Specific TOPIK level (I or II) is not differentiated in v1 — v1 targets both, without a level-specific curriculum yet.
- Vocabulary/grammar data source: not yet selected; the leading candidate is the open API from South Korea's National Institute of Korean Language, pending a technical evaluation in Chapter 5.
- AI sentence-checking will use the Google Gemini API (free tier), pending confirmation in Chapter 5's architecture decision.
- Platform: **Web first (v1, for course CS2028)**; a Mobile version is a future direction for a different course, not part of v1.
