# 3.4 — User Stories & Acceptance Criteria

**US-1 — Choose a learning goal**
As a new user, I want to select conversation or TOPIK as my goal, so that I see a learning path relevant to me.
- Given a first-time login, when the user has not yet selected a goal, then the app requires a goal selection before showing any path content.
- Given a goal is selected, when the user later changes it in settings, then the displayed path updates to match the new goal, while the previous goal's progress is kept (not deleted).

**US-2 — Follow a learning path**
As a learner, I want to move through vocabulary/grammar items in order, so that I build up knowledge progressively.
- Given a selected goal, when the user opens the learning path, then items are shown in a defined order with clear learned/not-learned state.
- Given an item is marked learned, when the user reloads the app, then that state is still reflected.

**US-3 — Scan text for reading practice**
As a learner, I want to scan a photo of Korean text, so that I can practice reading material I already have.
- Given a valid image containing Korean text, when the user uploads it, then extracted text is displayed within a reasonable time and is editable if OCR made an error.
- Given an image with no readable Korean text, when OCR fails, then the user sees a clear error and can retry with a different image.

**US-4 — Listen to the scanned text**
As a learner, I want to hear the scanned text read aloud, so that I can practice listening and mirror the pronunciation.
- Given extracted text is displayed, when the user taps play, then AI speech plays back exactly that text (including any manual corrections).
- Given playback fails (e.g. network error), when the user retries, then playback is attempted again without losing the extracted/edited text.

**US-5 — See my own progress**
As a learner, I want to see how much I've learned, so that I stay motivated and know what's left.
- Given the user has marked at least one item learned, when they open the progress view, then it shows counts of learned vs. remaining items for their current path only (not combined across goals).

**US-6 — Get AI feedback on a sentence I wrote**
As a learner, I want to write a Korean sentence and have AI check it, so that I know if I used correct grammar without needing a tutor.
- Given the user submits a non-empty sentence, when AI evaluates it as correct, then the app shows a clear confirmation (and may offer an optional, more advanced alternative phrasing).
- Given the user submits a sentence with an error, when AI evaluates it, then the app shows what was wrong and a corrected version, in Vietnamese-friendly explanation.
- Given a previous submission was checked, when the user submits a new sentence, then the AI treats it as an independent submission, not a continuation of a prior exchange.
- Given the AI service fails to respond (e.g. network/API error), when this happens, then the user sees a clear error and can retry without losing what they typed.

**US-7 — Review vocabulary for a topic**
As a learner, I want to review a topic's vocabulary in different quiz formats, so that I retain what I've studied.
- Given a topic the user has studied, when they enter review mode, then they can choose from at least: type-the-Vietnamese-meaning, type-the-Korean-word, and match-the-pairs.
- Given a type-in question, when the user's answer matches the expected value (allowing for reasonable formatting differences, e.g. extra whitespace), then it is marked correct.
- Given a matching question, when the user pairs a Korean word with its meaning, then correct pairs are visually confirmed immediately, incorrect pairs are indicated without ending the session.
- Given a review session ends, when the user finishes all questions, then they see a summary (e.g. score, which items to revisit).

**US-8 — Manage learning content as admin**
As an admin, I want to create, edit, and delete vocabulary/grammar items and organize them into topics, so that learning content stays accurate and current.
- Given valid item data (Korean word/phrase, Vietnamese meaning, topic), when the admin submits a new item, then it appears in the corresponding topic's learner-facing content immediately (or after the next content refresh — exact timing is a technical decision for later).
- Given an existing item, when the admin edits or deletes it, then learners see the updated or removed content the next time they load that topic.
- Given invalid or incomplete item data, when the admin submits it, then the form shows a clear validation error and does not save a partial item.

**US-9 — Manage user accounts as admin**
As an admin, I want to view registered users and lock/unlock accounts, so that I can respond to misuse or support issues.
- Given the admin opens the user list, when it loads, then it shows at least email and current lock status per user.
- Given a user account, when the admin locks it, then that user can no longer log in (existing sessions may remain valid until they expire — exact session-invalidation behavior is a technical decision for later).
- Given a locked account, when the admin unlocks it, then that user can log in normally again.

**US-10 — View usage statistics as admin**
As an admin, I want to see basic usage statistics, so that I understand how the site is actually being used.
- Given the admin opens the statistics view, when it loads, then it shows at least total registered users split by goal (conversation vs. TOPIK), and which topics are most studied.
- Given no data exists yet (e.g. a fresh install), when the admin opens this view, then it shows a clear empty state rather than an error.
